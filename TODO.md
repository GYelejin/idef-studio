# IDEF0 Studio — Roadmap & TODO

Данный документ содержит полный перечень запланированных возможностей, улучшений UX, поддержки стандартов IDEF0 (FIPS 183 / IEEE 1320.1), интеграций с LLM, а также разработки CLI и MCP-сервера.

---

## 1. Канонические функции IDEF0 (FIPS 183 / IEEE 1320.1)

- [ ] **Диаграмма дерева узлов (Node Tree Diagram / Node Index View):**
  - Полноэкранный визуальный граф иерархии проекта ($A-0 \to A0 \to A1, A2, A3 \to \dots$).
  - Отображение статуса декомпозиции каждого блока (лист / декомпозирован).
  - Быстрый переход в выбранную диаграмму по клику на узел дерева.
- [ ] **FEO-диаграммы (For Exposition Only):**
  - Возможность создавать иллюстративные схемы с флагом `isFEO: true`.
  - Отключение строгих правил валидатора для FEO (допустимо $< 3$ или $> 6$ блоков, свободный баланс внешних стрелок).
- [ ] **Глоссарий понятий и словарь данных (Data Dictionary / Glossary):**
  - Централизованная таблица потоков и данных проекта.
  - Назначение типов данных, форматов и текстовых спецификаций для сущностей стрелок.
  - Синхронизация типов данных с ICOM-промптами генератора кода.
- [ ] **Экспорт стандартизированных отчётов (FIPS 183 / ГОСТ):**
  - Генерация PDF-документации: титульный лист, диаграмма контекста $A-0$, диаграммы декомпозиций, таблицы ICOM и словарь данных.

---

## 2. Скорость и удобство моделирования (UX & Canvas)

- [ ] **Быстрое соединение стрелками из портов (Quick Connect / Hover Ports):**
  - При наведении курсора на блок динамически подсвечивать 4 порта (Input слева, Control сверху, Output справа, Mechanism снизу).
  - Создание стрелки через drag-and-drop прямо из порта источника к порту цели без ручного переключения инструментов.
- [ ] **Магнитные направляющие (Smart Alignment Guides):**
  - Отображение вспомогательных линий выравнивания при перемещении блока на одном уровне с соседними блоками по осям X и Y.
- [ ] **Клавиатурная навигация по иерархии (Keyboard-first navigation):**
  - `Enter` на выбранном блоке — мгновенный переход в его декомпозицию.
  - `Escape` или `Backspace` — подъём на родительскую диаграмму уровнем выше.
  - `B` — создание блока в точке курсора.
  - `Delete` / `Backspace` — удаление выбранного объекта с подтверждением для родительских блоков.
- [ ] **Миникарта холста (Minimap):**
  - Интерактивная плавающая миникарта в углу холста для быстрой ориентации и панорамирования по крупным диаграммам.

## 3. Инженерия и LLM (Кодогенерация и умный ассистент)

- [ ] **IDEF0 Copilot / T9 (Предиктивный ассистент при ручном моделировании):**
  - **ICOM Autocomplete:** при клике/наведении на любую грань блока (Control, Input, Mechanism, Output) всплывает умное контекстное меню с предложениями названий стрелок по смыслу блока (выбор по `Tab` / `Enter`).
  - **Tab-to-Next Block:** вытягивание стрелки в пустоту показывает полупрозрачный следующий логический блок процесса; нажатие `Tab` материализует его со стрелкой на холсте.
  - **Ghost Decomposition:** при переходе на пустую диаграмму декомпозиции показ полупрозрачного шаблона из 3–4 типовых подпроцессов с предварительно разведенными граничными стрелками (принять по `Enter`).
  - **Smart Semantic Linking:** при соединении двух блоков автоматический подбор наиболее логичной целевой грани (Input vs Control) и точного названия информационного объекта.
  - **Smart Context Healing (Quick Fix):** кнопка мгновенного исправления нарушений линтера (например, авто-добавление недостающей стрелки управления с верхней границы).
- [ ] **Text-to-IDEF0 (Генерация архитектуры модели по текстовому описанию):**
  - Создание диаграммы на основе текстового ТЗ/описания процесса (например, *"Опиши процесс обработки заказов в интернет-магазине"*).
  - Автоматическая расстановка блоков по диагонали и трассировка ICOM-стрелок.
- [ ] **Встроенный запуск Python-кода в браузере (Live Execution Playground):**
  - Выполнение сгенерированного Python-кода непосредственно в браузере через WebAssembly (Pyodide).
  - Тестовые входные аргументы для функций и просмотр результатов выполнения конвейера.
- [ ] **Архитектурный рефакторинг с помощью LLM:**
  - Анализ модели на предмет перегруженных блоков (свыше 6 связей) с предложением автоматической декомпозиции.

## 4. Консольная утилита (CLI — `idef-cli`)

Полнофункциональный консольный инструмент для автоматизации, CI/CD и работы без браузера:

- [ ] **Валидация и статический анализ (`idef-cli lint`):**
  - Проверка соответствия модели стандарту FIPS 183 в терминале.
  - Вывод ошибок: баланс границ, сиротские стрелки, циклы, неортогональные пути, превышение лимита 3–6 блоков.
  - Поддержка форматов вывода: читаемый текст, JSON, SARIF для GitHub Actions.
- [ ] **Экспорт (`idef-cli export`):**
  - Конвертация диаграмм модели в SVG, PNG и PDF.
  - Пакетная выгрузка всего проекта в ZIP-архив.
- [ ] **Кодогенерация из консоли (`idef-cli codegen`):**
  - Генерация Python-скрипта из файла модели `.idef0.json` через обращение к LLM API.
  - Поддержка параметров `--model`, `--api-url`, `--api-key`, `--output`.
- [ ] **Слияние и диффы моделей (`idef-cli diff` / `merge`):**
  - Семантическое сравнение двух версий моделей IDEF0 (добавленные/удаленные блоки, измененные ICOM-потоки).

## 5. Сервер контекста модели (MCP — Model Context Protocol)

Сервер протокола MCP (`idef-mcp`) для интеграции IDEF0 Studio с внешними AI-агентами (Claude Desktop, Gemini CLI, Cursor, Antigravity):

- [ ] **Ресурсы (MCP Resources):**
  - `idef://project/current` — получение текущей модели проекта в формате JSON.
  - `idef://diagram/{code}` — схема конкретной диаграммы ($A0, A1, \dots$) с полным списком блоков и связей.
  - `idef://dictionary` — глоссарий данных и интерфейсов.
- [ ] **Инструменты (MCP Tools):**
  - `idef_create_block` — создание блока с автоматической нумерацией и привязкой к родительской диаграмме.
  - `idef_create_arrow` — проведение стрелки с указанием роли ICOM (input, control, output, mechanism).
  - `idef_decompose_block` — создание дочерней диаграммы декомпозиции с автоматическим переносом граничных портов.
  - `idef_lint_model` — запуск линтера модели с возвратом списка нарушений стандартов FIPS 183.
  - `idef_synthesize_code` — генерация целевого программного кода по ICOM-структуре модели.
- [ ] **Промпты (MCP Prompts):**
  - `idef_architecture_review` — системный промпт для аудита архитектуры диаграммы экспертом по функциональному моделированию.
  - `idef_text_to_model` — структурированный шаблон преобразования бизнес-требований в сущности IDEF0.
